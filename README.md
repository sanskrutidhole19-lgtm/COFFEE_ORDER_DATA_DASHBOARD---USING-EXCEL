##### **<h1 align="center">Coffee Orders Analytics Dashboard 🚀</h1>**



###### **## About the Project**



The Coffee Orders Analytics Dashboard is a data analysis project developed using Microsoft Excel to visualize and monitor coffee sales data in an interactive format.



This dashboard converts raw order information into easy-to-understand visual reports that help identify trends, customer behavior, and product performance.



\---



###### **## Objective**



The main objective of this project is to:



\* Analyze coffee sales performance

\* Identify profitable products

\* Track customer purchasing patterns

\* Compare country-wise sales

\* Create a professional business dashboard



\---



###### **## Dashboard Components**



\### Sales KPIs



\* Total Revenue

\* Total Orders

\* Sales Performance Metrics



\### Analytical Sections



\* Country Sales Analysis

\* Customer Sales Analysis

\* Product-Based Insights

\* Monthly Sales Trends



\### Interactive Features



\* Slicers for filtering

\* Dynamic charts

\* Automated pivot table summaries
